動作環境
Node.js：最新版（推奨：LTS）
npm：Node.jsに同梱
手順
1. Node.jsをインストールする

Node.js公式サイトからLTS版をインストールする。

https://nodejs.org/

インストール後、以下のコマンドでバージョンが表示されることを確認する。

node -v
npm -v
2. プロジェクトを開く

提出したフォルダを任意の場所へ展開し、Visual Studio Codeで開く。

3. 必要なパッケージをインストールする

ターミナルを開き、プロジェクトのルートディレクトリで以下を実行する。

npm install

これにより、提出ファイルに含まれていないnode_modulesが作成される。

4. 開発サーバーを起動する
npm run dev
5. ブラウザで確認する

ターミナルに表示されたURL（例）

http://localhost:5173/

へアクセスすると、アプリケーションが表示される。
